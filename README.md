## 🏥 Healthcare RAG Assistant ##

AI-Powered Medical Information Retrieval System
A production-grade Retrieval-Augmented Generation (RAG) healthcare assistant that provides accurate, contextual, and explainable medical information by combining Large Language Models (LLMs) with domain-specific medical documents.
This system uses semantic search (FAISS) over healthcare PDFs and generates responses using Groq-hosted LLaMA 3.1, ensuring fast, reliable, and structured answers with proper source references.

## 🚀 Features ##
🔍 Context-Aware Medical Q&A using RAG
📄 PDF-based Knowledge Ingestion
🧠 Semantic Search with FAISS
⚡ Ultra-fast inference via Groq (LLaMA 3.1)
🖥️ CLI Interface for Developers
🌐 Professional Streamlit Web UI
📚 Transparent Source References
🧾 Medical Disclaimer Enforcement
🧰 Modular, scalable, and production-ready design
